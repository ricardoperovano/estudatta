# Convenções do frontend (apps/web)

Vite 7 + React 19 + TypeScript + Tailwind 3.4 + Radix (shadcn-like) + React Router 7 (modo data router) + TanStack Query 5 + React Hook Form + Zod + Dexie + Workbox. Node ≥ 20. Comandos: `npm run dev` (porta 5180, proxy `/api` → `http://localhost:8020`), `npm run typecheck`, `npm run lint`, `npm run build`, `npm run test`, `npm run test:e2e`. Este projeto é só o app; o site público fica em `estudatta-site` (HTML puro). Links para páginas do site usam `siteLink()` de `src/design/brand.ts`.

## Design system (obrigatório)
- Fonte de verdade: `src/design/tokens.css` (variáveis derivadas de `design-tokens.json`) mapeadas no `tailwind.config.ts`. **Nunca use hex direto**; use classes `bg-canvas`, `bg-surface`, `text-primary/secondary/tertiary`, `text-neutral-400/500`, `text-accent`, `bg-accent-900`, `text-pending`, `text-success`, `border-divider`, `shadow-sm/md/lg`, `shadow-accent-ring`, `shadow-inset-accent`, `rounded-md` (8px), `rounded-lg` (14px), `tnum` (números tabulares), `kicker`, `hr-fade`, `recovery-stripes`.
- Componentes prontos em `src/components/ui` (exportados por `@/components/ui`): `Button` (variantes `primary` = contorno acento, `secondary`, `ghost`, `ghost-muted`, `option`, `option-selected`, `danger`; tamanhos `sm|md|lg|xl|icon|icon-lg`; `block`, `loading`, `asChild`), `Input/Textarea/Select`, `Field` (label 12px, erro com ícone), `Card/CardKicker/CardTitle/CardBody/CardMeta` (`elev`, `accent`), `Tag` (`accent|neutral|outline|pending|success|info|error`), `Seg` (controle segmentado), `Switch`, `Checkbox`, `RadioGroup/RadioItem`, `Dialog/DialogContent` (`mode="sheet"` = folha inferior no celular), `Tabs/TabsList/TabsTrigger/TabsContent`, `GoalBar` (indicador segmentado registrado/falta/recuperação), `Bar`, `Legend`, `Toaster/toast`, `EmptyState/TrailGlyph`, `Banner` (`syncing|synced|offline|conflict|error|info`), `DurationStepper`, `DayPicker`, `Spinner`. Marca em `src/components/app/brand.tsx` (`Symbol`, `Logo`).
- Referências visuais: `../Identidade visual e design system PWA Estudatta/04 Telas Mobile.dc.html`, `05 Telas Desktop.dc.html`, `06 Landing.dc.html`, `03 Componentes.dc.html`, `design-system.md`; capturas em `docs/visual-comparison/reference/*.png`. Reproduza composição, hierarquia, tamanhos (título de tela 25px mobile / 32px desktop, cartão 16–24px de padding, kicker 11px maiúsculas) e textos. Para telas sem referência, derive dos padrões existentes.
- Mobile primeiro (360/390 px), tablet (768–1024: lateral 72px), desktop (1440: lateral 240px, conteúdo 12 colunas até 1200px). Tema claro e escuro via variáveis (não use `dark:`). Foco visível, alvos ≥ 44px, `prefers-reduced-motion` já tratado.
- Textos em pt-BR, vocabulário: "tempo a recuperar", "pendência", "meta de hoje", "sessão", "retomar o plano". Nunca nomes de tecnologia na jornada do usuário.

## Dados e API
- Tipos gerados de `backend/openapi.json` em `src/api/schema.d.ts` (`npm run api:types`); atalhos em `src/api/types.ts`. Cliente tipado `api` (openapi-fetch) + `unwrap()` em `src/api/client.ts`; `rawJson/rawFetch` para multipart/CSV. Erros: `ApiError` (`code`, `status`, `details`), `errorMessage(e)`, `isNetworkError(e)`.
- Hooks centrais em `src/api/queries.ts` (`useToday`, `useActivities`, `useActivity`, `useBalance`, `useActiveSession`, `useManualSession`, `useCreateActivity`, `useRecoveryPreview`, `useApplyRecovery`, `useToggleTask`, `useInvalidateAll`, `keys`). **Crie hooks novos no seu próprio módulo** (`src/api/<modulo>.ts`), não edite `queries.ts`/`client.ts`/`session.tsx`.
- Sessão: `useSession/useUser/useEntitlements/useAuthActions/usePublicConfig` em `src/api/session.tsx`. Direitos de acesso e saldo vêm do servidor (`entitlements.limits`); o frontend só mostra prévias.
- Offline: `src/offline/db.ts` (Dexie por usuário), `src/offline/sync.ts` (`enqueueOp`, `syncNow`, `useSyncStore`), `useOnline()` em `src/lib/online.ts`. Cronômetro em `src/app/timer/store.ts`.
- Formatação: `src/lib/format.ts` (`fmtMinutes` → "1h20", `fmtClock`, `fmtDayShort` → "quinta, 17 set", `fmtRange`, `fmtBRL`, `todayIso`).
- Rotas já registradas em `src/app/routes.tsx` (páginas são `export default`). Não edite `routes.tsx`, `main.tsx`, `index.html`, `vite.config.ts`, `components/ui/*`, `components/app/{shell,nav,brand}.tsx`. Componentes novos compartilhados vão em `src/components/app/<nome>.tsx` com nomes únicos.
- Nada de `localStorage` como substituto do backend (só preferências de exibição). Nada de botões sem ação real: se uma função depende de credencial ausente (IA, cobrança, push), mostre o estado honesto que o backend devolve (`503 ai_disabled`, `billing_mode=disabled`, `404` na chave VAPID).

## Qualidade
- `npm run typecheck && npm run lint` limpos antes de terminar. Testes de comportamento com Vitest + Testing Library quando úteis (`src/**/*.test.tsx`).
- Estados obrigatórios: carregando (`Spinner`), vazio (`EmptyState`), erro (`Banner kind="error"` com ação), offline (`Banner kind="offline"`), sincronizando/conflito quando aplicável.
